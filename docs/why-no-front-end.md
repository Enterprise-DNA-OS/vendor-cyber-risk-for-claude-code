# Why this desk has no front end

Vendor reviews are records and decisions: who owns the service, what evidence was checked, which findings remain open, and who accepted an exception until which date. A coding agent can work through the same CLI as an operator. Read-only HTML views give managers a useful report without another application to maintain.

UpGuard also supplies continuous internet-facing monitoring, a proprietary rating service, vendor portals, shared security profiles and notifications. This repository does not implement those services or imply that an imported score stays current. A browser interface also gives multi-user authentication, forms, mobile convenience and simultaneous collaboration. There is no mobile or offline synchronisation here. The local embedded store is single-process.

Use the desk for assessment administration. Keep external monitoring where needed. Enterprise DNA builds the chosen connections, a web view or intake forms, and access controls into a customised installation. Do not expose the database owner's connection or private HTML reports publicly.
